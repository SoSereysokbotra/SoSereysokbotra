## 🚀 Featured Projects

### 🤖 [Intelligent 6-DOF Robotic Arm](https://github.com/sosereysokbotra)
> **Embodied AI · ESP32 · Computer Vision · Python · PlatformIO**

A natural-language controlled robotic arm that can "pick up the red screwdriver" or "sort these objects by color." ESP32 + PCA9685 driving 6 servos, overhead camera for perception, WebSocket bridge to a Python backend running inverse kinematics and vision.

- Phases 0–3 software complete: **69 unit tests, ruff + mypy clean, ~2,125 lines of Python**
- ChArUco camera calibration, closed-form top-down IK, HSV object detection pipeline
- Designed as a portfolio project demonstrating the full stack: AI · robotics · CV · system design

### 💼 [JobFits — AI-Powered Job Matching](https://github.com/sosereysokbotra)
> **NestJS · Next.js 15 · FastAPI · Prisma · PostgreSQL · Google Cloud Run**

Production-grade job-matching platform with a DDD-layered backend, semantic matching AI service, and a Chrome MV3 extension.

- **107 API endpoints · 111 backend tests passing · 24 Prisma models**
- Built a full **RAG + LLM evaluation harness**: `MatchLabel` model, human-editable JSONL evals, pure metric functions (`recallAtK`, `reciprocalRankAtK`, `ndcgAtK`) with Jest tests
- Deployed on Google Cloud Run with event-driven architecture (BullMQ)

### 🚗 [Cambodian ALPR System](https://github.com/sosereysokbotra)
> **YOLOv10 · CRNN · ESP32 · MQTT · Deep Learning**

Automatic License Plate Recognition tailored for Cambodian plates, targeting parking and gate automation in Phnom Penh. Edge inference on ESP32, MQTT for coordination, deep learning pipeline for detection + character recognition.

### 🖥️ [Agent V3 — Desktop AI Assistant](https://github.com/sosereysokbotra)
> **Qwen2.5-0.5B · BLIP · Whisper · Python · Windows**

Persistent background AI assistant with system tray, global hotkeys, voice I/O (Whisper + pyttsx3), vision (BLIP), and a memory database. Local-first LLM inference with a planner/executor architecture.

### 🧬 [Modern Transformer Ablation Study](https://github.com/sosereysokbotra)
> **PyTorch · CUDA · Cloud GPU · Research**

From-scratch decoder-only Transformer implementing the modern stack (pre-norm, RMSNorm, RoPE, SwiGLU, GQA, FlashAttention), then ablating each component back to its 2017 equivalent to measure the impact. Every line of model code hand-written for understanding.
